◆ ejecutar_voraz()

int ejecutar_voraz ( int  n,
const vector< vector< int > > &  G 
)

Ejecuta la heuristica Voraz (Greedy) para el TSP restringido.

Estrategia: Desde el nodo actual, viaja al vecino no visitado con menor coste, respetando la restriccion de no ir al nodo consecutivo (i+1).

Parámetros
nNumero de nodos.
GMatriz de adyacencia.
Devuelve
int Coste total del camino encontrado, o -1 si no se encontro solucion factible.

◆ main()

int main ( )

Funcion principal.

Gestiona la experimentacion y generacion de archivos.

  1. Crea archivos .dat para guardar los resultados.
  2. Itera para diferentes tamanyos de grafo (n_min a n_max).
  3. Para cada tamanyo, ejecuta 'repeticiones' veces generando grafos aleatorios.
  4. Calcula promedios de accesos y calidad de la solucion.
  5. Escribe los resultados en los archivos.
Devuelve
int 0 si la ejecucion es correcta, 1 si hay error de ficheros.
